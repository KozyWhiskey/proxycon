# Approved ProxyCon fonts

Self-hosted Latin WOFF2 subsets extracted from the approved Ember Folio reference. Fraunces and Manrope support weights 400–700; IBM Plex Mono includes 400 and 500. All font families are distributed under SIL Open Font License 1.1; family notices and license terms are included alongside these files.

Upstream distributions: https://github.com/google/fonts/tree/main/ofl/fraunces, https://github.com/google/fonts/tree/main/ofl/manrope, https://github.com/google/fonts/tree/main/ofl/ibmplexmono.
